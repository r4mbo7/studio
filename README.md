# BrotherCos

Site du studio BrotherCos, publié sur [studio.cdelaroche.fr](https://studio.cdelaroche.fr) par GitHub Pages depuis la racine de `main`.

- `index.html` : la page, statique, sans build.
- `design/` : la charte réutilisable (jetons CSS, logos SVG et leur générateur). Voir [design/README.md](design/README.md).
- `assets/` : images du site.

Voir en local : `python3 -m http.server` puis http://localhost:8000.
